# Campaign for North Africa

You will need a copy of the rules, counters, and map for **The Campaign for North Africa**, a group of players, and a lot of time to play this game.

The materials are available on the [SPI Extras site](https://www.spigames.net/rules_downloads.htm).
You're responsible for finding players and time.
